## Review mandate

This is a two-pass engineering review of the complete controller repository.
The first pass covers architecture, correctness, security, safety, reliability,
memory use, performance, maintainability, UI behavior, network and printer
protocols, build/release configuration, and documentation consistency. Findings
that can be corrected safely in scope will be fixed and validated. The second
pass is a separate bug hunt over the resulting codebase.

The review will not:

- Send destructive printer commands.
- Interrupt an active P1S print.
- Format or modify either SD card.
- Log or expose Wi-Fi passwords, printer access codes, or private credentials.
- Treat a successful build as proof of behavior that requires hardware observation.
