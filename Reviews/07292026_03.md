## Safety boundary

Dima reported an active print with approximately 45 minutes remaining.
Throughout that job, this implementation run will not:

- deploy or flash controller firmware;
- reset or attach a USB serial monitor to the controller;
- send a printer command;
- change printer/network profiles;
- access or modify either SD card;
- run a destructive or state-changing hardware test.

Source, host-test, static, and local firmware-build work may continue. Hardware
qualification is recorded separately and is never inferred from a build.
