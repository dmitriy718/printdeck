## Photography notes

- Use soft, even light and clean the display and enclosure before shooting.
- Photograph the screen near eye level. Keep verticals straight.
- Prefer the original camera files; avoid screenshots embedded in messaging apps.
- Crop to the placeholder’s aspect ratio before insertion. Do not stretch images.
- Keep edits factual: exposure, white balance, crop, and dust cleanup are appropriate; do not add nonexistent hardware or UI elements.
- If an active print is shown, use a model you created or have permission to publish.
- Review every image at 100% zoom before sending. Printer stickers and reflected screens often reveal identifiers that are easy to miss.

## Optional supplemental images

These are not required for the current six-page overview, but they may be useful for a follow-up email or project website:

- **Controller interface prototype.** A clean exported UI screenshot if a supported capture path is added.
- **Wi-Fi and P1S pairing flow.** Use only staged values; never show a real access code.
- **Guarded OTA screen.** Show the physical enable control without displaying a private controller address.
- **SD-card and enclosure detail.** Useful when file workflows and enclosure work are further developed.
